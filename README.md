# Time-Series Activity Classification

This project uses the AReM sensor dataset to classify physical activities from time-series measurements.

- Split sensor recordings into segments and extract statistical features.
- Build binary and multiclass classifiers with logistic regression and Naive Bayes.
- Compare model results on held-out data.

<a id="中文"></a>
# 时间序列活动分类

本项目使用 AReM 传感器数据集，根据时间序列测量值识别不同的活动。

- 将传感器记录切分为多个片段，并提取统计特征。
- 使用逻辑回归和朴素贝叶斯完成二分类与多分类。
- 在留出的测试数据上比较模型表现。
